# typino

> 타자 치면 노래가 된다 — [typino.m1k.app](https://typino.m1k.app)

계이름 키패드가 건반이다. `도도솔솔 라라솔` 을 누르면 작은 별이 나온다. 누르는 빠르기가 곧 노래의 박자.

```
도 레 미
파 솔 라
♭ 시 ♯      ← 샵·내림·옥타브는 자유 모드에만
▼ 옥타브 ▲
```

- **곡에선 아무 키나** — 컴퓨터 자판·폰 자판(입력칸)·건반 아무거나 다다다 치면 곡의 다음 음이 난다. 치는 빠르기가 곧 박자. 자판은 누르고 있으면 소리가 이어진다. "계이름 맞추기"를 켜면 맞는 건반만 맞다
- 모든 건반은 손가락마다 따로 — 여러 건반을 동시에 누를 수 있다
- **자유** — 악보 없이 외운 계이름을 누른다. 높이는 옥타브 버튼으로 내가 정하고, 반주 코드는 누른 음을 품는 것으로 알아서
- **곡** — 다음에 누를 건반이 주황으로 켜진다. 앞 음이 제 길이만큼 다 울린 뒤에 켜지니 불이 곧 박자다. ♪ 들어보기 를 누르면 건반에 불을 켜 가며 곡을 한 번 들려준다. `솔ㅡ` 처럼 작대기가 붙은 음은 그 박만큼 쭉 누른다 — 누르는 동안 소리가 이어지고 떼면 끝난다. 맞으면 곡에 적힌 높이로 울리고 코드가 바뀌는 자리에선 반주가 깔린다. 틀리면 누른 음이 나고 자리는 그대로
- 작은 별·생일 축하·파헬벨 캐논·징글벨·환희의 송가·고요한 밤·모차르트 작은 밤의 음악·베토벤 운명. 저작권이 끝난 선율만, C장조로
- **내 곡** — 계이름을 직접 적으면 그 곡으로 따라친다. `도도솔솔 라라솔ㅡ` 처럼 ㅡ 는 한 박 더, `높도`·`낮시` 로 옥타브, 줄바꿈은 다음 줄. 반주는 알아서. 적은 곡은 이 브라우저에만 남는다

```bash
npm install
npm run dev
npm run check   # 계이름 변환·옥타브 점검
```

Vite + React + [@m1kapp/kit](https://github.com/m1kapp/kit)

## 소리

- 피아노는 [Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3) 녹음(Alexander Holm, CC BY 3.0)을 단3도마다 한 장씩, 모노 64kbps 6초로 줄여 `public/piano/` 에 둔다. 사이 음은 재생 속도로 낸다. 못 받으면 삼각파로
- 방 울림(잔향)을 살짝 지난다
- 왼손은 누를 때마다 쿵(베이스)·짝(화음)을 번갈아 친다 — 내 손 빠르기가 곧 반주 빠르기
- 현악이 지금 코드를 길게 깐다. 3초 안 누르면 걷힌다
- 드럼(킥·스네어·하이햇)도 누를 때 같이 친다. 어울리는 곡(생일·징글벨·환희의 송가)과 자유·내 곡에서 켜져 있고 화면의 "드럼"으로 끄고 켠다
