# typino

> 타자 치면 노래가 된다 — [typino.m1k.app](https://typino.m1k.app)

계이름 키패드가 건반이다. `도도솔솔 라라솔` 을 누르면 작은 별이 나온다. 누르는 빠르기가 곧 노래의 박자.

```
도 레 미
파 솔 라
♭ 시 ♯      ← 샵·내림·옥타브는 자유 모드에만
▼ 옥타브 ▲
```

- **자유** — 악보 없이 외운 계이름을 누른다. 높이는 옥타브 버튼으로 내가 정하고, 반주 코드는 누른 음을 품는 것으로 알아서
- **곡** — 다음에 누를 건반이 주황으로 켜진다. 앞 음이 제 길이만큼 다 울린 뒤에 켜지니 불이 곧 박자다. ♪ 들어보기 를 누르면 건반에 불을 켜 가며 곡을 한 번 들려준다. `솔ㅡ` 처럼 작대기가 붙은 음은 그 박만큼 쭉 누른다 — 누르는 동안 소리가 이어지고 떼면 끝난다. 맞으면 곡에 적힌 높이로 울리고 코드가 바뀌는 자리에선 반주가 깔린다. 틀리면 누른 음이 나고 자리는 그대로
- 작은 별·생일 축하·파헬벨 캐논·징글벨·환희의 송가·고요한 밤·모차르트 작은 밤의 음악·베토벤 운명. 저작권이 끝난 선율만, C장조로
- **내 곡** — 계이름을 직접 적으면 그 곡으로 따라친다. `도도솔솔 라라솔ㅡ` 처럼 ㅡ 는 한 박 더, `높도`·`낮시` 로 옥타브, 줄바꿈은 다음 줄. 반주는 알아서. 적은 곡은 이 브라우저에만 남는다

```bash
npm install
npm run dev
npm run check   # 계이름 변환·옥타브 점검
```
