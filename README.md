# typino

> 타자 치면 노래가 된다 — [typino.m1k.app](https://typino.m1k.app)

자판이 건반이다. 화면에 나온 계이름을 그대로 치면 그 음이 난다 — `도도솔솔 라라솔` 을 치면 작은 별이 나온다. 치는 빠르기가 곧 노래의 박자.

- **계이름 한 글자 = 음 하나** — 글자를 다 치는 순간 바로 울린다. 코드가 바뀌는 음을 치면 베이스+3화음 반주가 같이 깔린다
- **틀려도 친 대로** — 라 자리에 레를 치면 레가 난다. 진짜 건반처럼
- **곡** — 자유(악보 없이 — 옥타브는 앞 음에 가까운 쪽, 반주 코드는 자동)·작은 별·어린 양·환희의 송가·생일 축하·파헬벨 캐논(어려움). 저작권이 끝난 선율만, C장조로

키 이벤트가 아니라 입력값의 변화를 읽어서, 모바일 가상 키보드에서도 똑같이 동작한다.

```bash
npm install
npm run dev
npm run check   # 계이름 변환·옥타브 점검
```
