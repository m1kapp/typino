# typino

> 타자 치면 노래가 된다 — [typino.m1k.app](https://typino.m1k.app)

곡의 음정은 정해져 있다. 화면에 나온 가사를 한 글자 칠 때마다 그 곡의 다음 음이 나간다. 피아노 건반 대신 자판을 치는 셈이라, 치는 빠르기가 곧 노래의 박자다.

- **음표 하나 = 한글 한 글자** — 가사 글자 수와 음표 수가 딱 맞는다 (`npm run check` 가 지킨다)
- **치는 족족** — 글자를 다 치는 순간 바로 울린다. 선율 밑에 3도 아래 음을 깔아 화음으로
- **틀리면 툭** — 틀린 글자는 노래 대신 낮은 소리
- **곡** — 작은 별(프랑스 민요)·환희의 송가(베토벤). 선율은 저작권이 끝난 것만, 가사는 새로 붙였다

키 이벤트가 아니라 입력값의 변화를 읽어서, 모바일 가상 키보드에서도 똑같이 동작한다.

```bash
npm install
npm run dev
npm run check   # 가사 글자 수 = 음표 수 점검
```
