# typino

> 치면 시가 노래가 된다 — [typino.m1k.app](https://typino.m1k.app)

한글은 글자가 화음이다. 글자를 다 치는 순간 초성·중성·종성 세 음이 한 화음으로 띵 울린다. 다 치면 띵, 리 치면 띵.

- **자모 = 음 높이** — 자음은 낮은 음, 모음은 높은 음
- **글자 = 화음** — 받침은 한 옥타브 아래 베이스
- **C 펜타토닉** — 어떤 글자를 쳐도 화음이 어긋나지 않는다
- **치는 족족** — 다음 글자를 기다리지 않고 그 글자가 맞는 순간 바로 울린다
- **따라 치기** — 진달래꽃(김소월)·서시(윤동주). 맞게 쳐야 화음이 난다

키 이벤트가 아니라 입력값의 변화를 읽어서, 모바일 가상 키보드에서도 똑같이 동작한다.

```bash
npm install
npm run dev
npm run check   # 자모 분해·음 배정 점검
```
